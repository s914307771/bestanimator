# Double Bubble Show — карточки персонажей с фото в CRM

## Изменения
- Вкладка «Персонажи»: изображения из `public.characters.image_url` (того же каталога, что использует Telegram Mini App).
- Вертикальный блок с `object-fit: contain`, без обрезания ног или головы. При отсутствующем фото — заглушка 🎭.
- Отображается категория, статус, наличие публикации в Mini App и премиальность.
- Существующие «Календарь», «Архивировать» и создание персонажа сохраняются.
- Никаких SQL, новых таблиц, Edge Functions, секретов и изменений в бронировании.

## Установка (GitHub)
ВАЖНО: файлы подготовлены по имеющемуся архиву `bestanimator-main.zip`. В текущем репозитории могли появиться более новые правки. Если файлы отличаются от текущих, не заменяйте их полностью — примените изменения из `changes.diff` вручную к актуальной ветке.

1. Создайте в GitHub ветку `feature/crm-character-photos` из актуальной `main`.
2. Замените / обновите `best-animator-cloud/app/page.tsx` и `best-animator-cloud/app/globals.css` из этого пакета. НЕ файл `web/index.html` (он относится к Telegram Mini App).
3. Выполните `npm run build` локально либо проверьте Preview Deployment Vercel для ветки.
4. Убедитесь, что на CRM отображаются изображения и работают «Заказы», «Календарь», «Персонажи».
5. Только после проверки объедините ветку с `main`.

## Откуда фото
Из `public.characters.image_url`. В карточке без ссылки или при ошибке загрузки появится заглушка.

## Что НЕ реализовано
Пока нет прямой загрузки новых изображений с компьютера в CRM и редактирования ссылок; для этого отдельно нужны Storage policies, UI и проверки прав. Этот патч добавляет именно визуальные карточки.
